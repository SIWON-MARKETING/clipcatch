## 사용자 요청 5개
1. 별도 로컬 영상 미리보기 버튼 숨김; 기존 미리보기 확대.
2. 구간 다운로드에서 H.264 + AAC-LC 오디오로 재인코딩. 오디오 트랙 누락 시 무음 완성본으로 처리하지 않음.
3. 다운로드 중간 구간 파일은 앱 데이터 내 영수증(작업ID) 검증된 임시 폴더에서 보관. 성공 시 최종 영상만 게시하고 중간 파일 삭제. 기존 사용자 파일은 보존.
4. 캐러셀 영상은 원본 프레임 전체가 보이게 비율 유지·가운데 정렬; 노란 번호 제거.
5. 본문 배경 그라데이션 제거, 단색 검정.
