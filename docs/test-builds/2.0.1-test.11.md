## 빌드와 검사

`.github/workflows/segment-preview.yml`이 정확한 이벤트 소스 커밋을 체크아웃하고 test.11 메타데이터로 빌드한다. 전달 ZIP의 `SOURCE-COMMIT.txt`와 `SHA256SUMS`를 실행파일의 버전·Go 빌드 메타데이터와 대조한다. 이 문서는 빌드 전 요구사항이며 검사 통과를 뜻하지 않는다.

검사는 개발 도구가 앱 PATH에 없는 새 Windows 프로필에서 해당 EXE를 직접 실행한다. 앱이 영상 도구를 스스로 준비하는지, 폰트 미설치 안내와 원본 POP 폰트 인식, 실제 C:→D: H.264/AAC 구간 저장, 기본/편집 캐러셀 1080×1350 출력과 오디오 디코딩, 기존 데이터 보존을 확인한다. 폰트는 SHA-256으로 원본과 일치해야 하며 임시 프로필 밖으로 전달하거나 증거·ZIP·Git에 포함하지 않는다.

별도 Chromium 검사에서 시·분·초 입력, 확대 미리보기의 실제 너비, 기본/세부 편집과 구간 API 요청을 확인한다. 결과와 실패/미실행 항목은 Actions 로그와 QA JSON을 기준으로 한다.

## 미완료와 사용 한계

- 태우님 또는 사용자 실제 PC에서의 확인은 아직 하지 않았다.
- 브릿지 본문 에셋과의 동일성은 아직 검증·수정되지 않았다. 기존 별도 본문 배치를 브릿지와 같다고 표시하지 않는다. 실제 기준 에셋을 대조해야 한다.
- 완성된 MP4는 문구가 영상에 합쳐진 결과물이다. 편집 프로젝트를 다른 PC로 넘기는 기능은 구현하지 않았다.
- 테스트판 자동 업데이트는 비활성화되어 있다. 기존 Preview 화면의 종료 버튼을 누르고 새 실행파일을 실행해야 한다.
- `main` 운영판에 병합하거나 정식 릴리스를 배포하지 않는다.
