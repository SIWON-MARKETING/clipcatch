ClipCatch v2.0.1

회사 저장소로 업데이트 연결 복구
- 업데이트 확인·다운로드·공유 링크를 SIWON-MARKETING/clipcatch로 연결했습니다.
- 저장소 이전 후 새 실행파일 주소를 거절하던 문제를 수정했습니다.
- 예전 저장소 주소가 남은 업데이트 캐시는 폐기하고 공식 정보를 다시 확인합니다.
- 실행파일·체크섬·앱 이름·버전·정식/테스트 채널 검증과 교체 실패 시 복구 기능을 유지합니다.

기존 사용자 적용 방법
1. 진행 중인 작업을 마치고 필요한 결과를 저장하세요.
2. 아래 회사 공식 링크에서 새 ClipCatch.exe를 받아 한 번 실행하세요.
   https://github.com/SIWON-MARKETING/clipcatch/releases/latest/download/ClipCatch.exe
3. 화면에 v2.0.1이 표시되는지 확인하세요. 기존 설치 폴더·기록·설정·저장 파일을 삭제할 필요는 없습니다.

v2.0.0 이하의 앱에는 예전 저장소 주소 검증이 들어 있어 이번 버전만 수동 교체가 필요합니다. 수정판부터 이후 업데이트는 회사 저장소를 사용합니다. 새 버전 설치는 기존처럼 업데이트 버튼으로 진행합니다.

유지되는 동작
- 정식판은 실행·탭 복귀·사용할 때만 확인하며, 같은 결과를 1시간 동안 재사용합니다.
- 마지막 탭을 닫았을 때의 종료 대기와 진행 중인 작업 보호를 유지합니다.
- Preview/TEST2 기능이나 초안 PR은 정식판에 합치지 않습니다.

검증
- PR과 main에서 Linux 회귀·실제 미디어 검사 및 Windows 설치·교체·롤백·브라우저 검사를 수행합니다.
- 게시 후 공식 공개 파일이 검증한 실행파일과 일치하는지, 기존 v2.0.0·1.9.9·1.9.8·1.9.6에서 새 실행파일 실행으로 교체되는지 추가 검사합니다.
- 디자인팀 실제 PC의 보안 정책이나 모든 사용자 환경을 검사했다는 의미는 아닙니다.
